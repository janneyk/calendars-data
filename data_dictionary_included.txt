Data Dictionary for included_calendars.csv


Column:			Explanation


ID:			An ID unique to that calendar.
			(The ID is primarily based on the eHRAF culture
			code. If multiple calendars exist for the same
			culture, they receive suffixes _A, _B, _C, etc.
			If a calendar does not correspond to any culture
			in eHRAF World Cultures, it is assigned an ID
			beginning with X, followed by a number.)

Culture_code:		Code of the culture on eHRAF World Cultures (if
			available).

Culture_code_Arc:	Code of the culture on eHRAF Archaeology (if
			available).

Culture_name:		Name of the culture or the population that
			developed/mainly uses the calendar.

Continent:		Continent where the population/culture is mainly
			located, extracted from eHRAF where possible.

Subsistence_type:	Subsistence type of the population/culture,
			extracted in principle from eHRAF.

Calendar_name:		Name of the calendar in question.

Solar_year:		A solar year is a time unit that tracks
			(imperfectly) the trajectory of the Earth around
			the Sun, typically lasting around 365 days.We
			code solar years as explicitly present based on
			the following criteria:

			Years are defined as sets of days. There is
			evidence that days are counted to determine the
			length of the solar year, rather than only
			observing seasonal changes. We accept two ways of
			counting days:

			1. Counting days directly (e.g. “It’s the nth day
			of the year”).

			2. Counting days through months (lunar or solar),
			if the days within each month are counted
			(instead of tracking months merely observing the
			phases of the moon).

			We also accept solar years where the number of
			days varies from year to year if this variation
			is used to maintain alignment with the solar
			cycle over time, in other words if it is part of
			an intercalation system.

			Calendars that track the solar year by
			alternating between 12 and 13 lunar months are
			very common (generally known as lunisolar
			calendars). Even if such a year is sometimes
			referred to as a “lunar year” in the source, the
			regular addition or removal of a month provides
			strong evidence that the year being tracked is
			solar. Therefore, we code it as a solar year.

Solar_month:		Solar months are subdivisions of the solar year
			into named or numbered groups of days, each
			covering a comparable span (the best known
			example is the months we use in our calendar:
			January, February, March, etc.). We code solar
			months as explicitly present based on the
			following criteria:

			1. There is a solar year present in the calendar.

			2. The solar year is divided into units that do
			not follow the lunar cycle. These units have to
			be counted in days.

			There is no restriction on the number of days (it
			can be short) and no requirement that all units
			should be the same number of days (in our
			Gregorian calendar that is not the case). The
			second criterion excludes any imprecise
			subdivisions of the year, such as seasons in most
			calendars, which should not be confused with
			solar months.

Lunar_month:		A lunar month is a time unit that tracks
			(imperfectly) the trajectory of the Moon around
			the Earth.

			We code lunar months as explicitly present if
			there is evidence that days are counted or
			individually named to determine the length of the
			lunar cycle, rather than only observing the
			phases of the moon.

			Given that a synodic lunar month is around 29.5
			days (and the sidereal lunar month around 27.3
			days), the number of days in a lunar month cannot
			remain constant without an intercalation system.
			Hence, even if ethnographers mention a "lunar
			month," we should seek evidence on whether the
			day count in each month varies, or whether the
			lunar month truly follows the lunar cycle to
			determine if it is a lunar month. Therefore, if
			the number of days is always the same, then it
			cannot be a lunar month, unless some other kind
			of intercalation system is mentioned that
			corrects for the drift, or if the source provides
			other evidence for the month tracking the lunar
			cycle (for instance, each month beginning with
			the new moon).

Lunar_year:		Lunar years are constructed by combining lunar
			months to form bigger units. We code lunar years
			as explicitly present if the calendar meets the
			following criteria:

			1. There are lunar months present in the
			calendar.

			2. The source mentions a cycle built on multiple
			lunar months, and there is no intercalation
			system (e.g. alternating between 12 and 13 lunar
			months) which would make this cycle track the
			solar year.

			If an intercalation method is present, then the
			year is used to track the solar cycle, and we
			therefore code the lunar year as absent and code
			the year as solar year instead.

Lunar_week:		Lunar weeks are subdivisions of a lunar month. We
			code lunar weeks as explicitly present if the
			calendar meets the following criteria:

			1. There are lunar months explicitly present in
			the calendar.

			2. The lunar month is divided into smaller
			periods, which have a specified length in days.
			Mere observation of lunar phases or the
			waxing/waning moon does not count as a lunar
			week.

			3. In order to remain aligned with the lunar
			month, lunar weeks cannot be of equal length. A
			lunar month can be divided into 3 weeks of 10,
			10, and 9 days, for instance.

Arbitrary_week:		An arbitrary week is a time unit defined as a
			fixed number of days (seven in our calendar) that
			recurs periodically, always identical in length.
			It is important to note that arbitrary weeks are
			not subdivisions of months or years. Years
			typically cannot be neatly divided into an
			integer number of weeks (the same is true for
			months), and the start of a week does not have to
			coincide with the start of a year or month (it
			typically does not).

			This is a key difference from lunar weeks, which
			are strict subdivisions of the lunar month. In
			calendars with lunar weeks, the start of all
			lunar months is also the start of a lunar week,
			and all lunar months are made up of a fixed
			integer number of weeks.

			We code arbitrary weeks as explicitly present if
			the calendar meets the following criteria:

			1. There is evidence of a recurrent cycle of days
			(without breaks).

			2. The unit does not vary in size from one cycle
			to the next (e.g. every week lasts five days).

			3. The unit is not constructed by dividing or
			combining other units (other than the day), but
			is truly independent.

			Note on Judeo-Roman weeks:

			Because the seven-day Judeo-Roman week is widely
			used and generally familiar to ethnographers,
			source materials may not describe it in as much
			detail as other calendrical units. Thus, we allow
			its presence to be inferred through the following
			evidence:

			1. Direct use of weekday names or translations of
			them. These names are conspicuous because they
			often use a well-known planetary scheme (e.g.
			Sunday / Dies solis, etc. = sun, Monday / Dies
			lunae etc. = moon, etc.), and/or clearly mark out
			one day as a day of ceremony.

			2. Descriptions of the weekly activities in the
			given society (which do not appear to be merely
			the ethnographer’s own way of describing time).

			3. A celebration of Jum'ah (Friday), Sabbath
			(Saturday), or Lord’s Day (Sunday), or their
			local equivalents.

SY_length:		The length of a normal, non-leap solar year in
			days.

LY_length:		The length of a normal, non-leap lunar year in
			days.

SM_length:		The length of the solar month in days. If the
			length changes from month to month, we code the
			length of the shortest one in a normal year.

LM_length:		The length of the lunar month in days. Since the
			length changes from month to month, we code the
			length of the shortest one.

LW_length:		The length of the lunar week in days. Since lunar
			weeks can’t be the same length every time, we the
			most frequent length.

AW_length:		The length of the arbitrary week. If there are
			multiple arbitrary weeks in use, we code the
			shortest.

AW_extra_length:	If there are additional arbitrary weeks, their
			lengths are presented here.

AW_supercycle_length:	If there are superordinate (supercycle) units
			created by combining multiple arbitrary weeks,
			their lengths are presented here. We code only
			the shortest.

AW_N:			The number of different arbitrary weeks used in
			the calendar. (Superordinate units created from
			arbitrary weeks are not included here.)

Week_concept:		If there is an arbitrary week, is it a
			Judeo-Roman week or not? If there is at least one
			instance of a non-Judeo-Roman week, we code this
			field as 'Indigenous'.

SCCS:			Is the culture part of Murdock and White's (1969)
			'Standard Cross-Cultural Sample'?

Sources:		List of sources used to make the coding
			decisions.
